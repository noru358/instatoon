# Font assets

## Current status

NotoSansKR-Regular.woff2 is preserved as a deterministic Korean fallback/test font.

It is NOT automatically the final brand/comic lettering font for INSTATOON_STYLE_v2.0.

The current visual direction favors larger, friendly, highly readable comic-like Korean lettering. Final publish font selection remains a separate design decision and requires user approval.

Until a new font is explicitly approved:
- use Noto Sans KR only for deterministic layout/QC prototypes;
- do not infer that its visual personality is locked;
- preserve text as editable vector/layout objects so the font can be swapped without regenerating art.
