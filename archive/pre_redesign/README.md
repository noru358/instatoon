# Pre-redesign episode archive

This directory preserves retired episode packages only as non-authoritative failure evidence and regression-test fixtures.

Rules:
- files under `archive/pre_redesign/` are never active production authority;
- do not render, repair, extend or resume these episodes;
- do not derive a current `Active episode` value from this directory;
- project-wide lessons belong in canonical project authority files, not in the archived episode package;
- a fresh production episode may reuse an episode number without inheriting archived episode facts.
